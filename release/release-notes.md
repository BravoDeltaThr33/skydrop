The Now screen's **Next 12 hours** is one chart now, with precipitation colored by type.

## Downloads

| System | File | Install |
|---|---|---|
| Debian, Ubuntu, Mint | `skydrop_3.15.0_all.deb` | `sudo apt install ./skydrop_3.15.0_all.deb` |
| Any Linux | `skydrop-3.15.0-linux.tar.gz` | `tar xzf skydrop-3.15.0-linux.tar.gz && cd skydrop-3.15.0 && ./install.sh` |
| macOS | `skydrop-3.15.0-macos.zip` | unzip, then `cd ~/Downloads/skydrop-3.15.0-macos && bash install.sh` |
| Windows 10 and 11 | `skydrop-3.15.0-windows.zip` | Extract All, then double-click `install.cmd` |
| Screenshots | `skydrop-3.15.0-screenshots.zip` | every screen, theme, CRT phosphor and drawing mode |

`SHA256SUMS.txt` has the checksums. skydrop starts with the weather for Dallas,
TX (75201); press `z` to set your own ZIP code. No account or API key is needed.
Installing over 3.14.0 keeps your settings.

## What's new

* **One chart for the next 12 hours**, three rows shorter than the two it
  replaces: the temperature along the top and, under it, a bar for each hour
  precipitation may fall, as tall as its chance, with the chance over it.
* **Precipitation by type, in weather radar's colors**: rain in shades of green
  from light to heavy, thunderstorms gold, snow white, sleet pink, freezing rain
  magenta and a wintry mix violet. The key under the chart, now called
  Precipitation, names the kinds coming in the next 12 hours.
* A forecast of "Wintry Mix" gets the wintry mix icon.
